# Kev Agent Kit Documentation

Kev Agent Kit connects a local decision model to Codex, Claude Code, and Google
Antigravity. Start with the user guide; you do not need to understand model training.

| I want to… | Read |
| --- | --- |

| Submit a complete example directly to the API | [Support-triage request](../examples/support-triage.json) |
| Understand training, architecture, and benchmarks | [Upstream documentation](../README.md#upstream-kev) |
| Read model limitations | [Original model card](../MODEL_CARD.md) |

Local interfaces, while the corresponding services are running:

- Playground: http://127.0.0.1:8009
- Interactive API documentation: http://127.0.0.1:8008/docs
- Model information: http://127.0.0.1:8008/v1/models

The original model and research are by
[Jared Palmer and the Kev contributors](https://github.com/jaredpalmer/kev).
Busy Office adds the local Docker setup, agent connections, and usage documentation.
